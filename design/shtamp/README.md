# ШТАМП — мова інтерфейсу ТІТАЛ

**Версія 1.0.** Дизайн-система ERP Металообробка. Придатна до перенесення
в будь-який інший продукт — Pulse, CRM, внутрішні панелі.

---

## Одна ідея

**Екран — це аркуш робочої документації, а не застосунок.**

Усе інше випливає звідси: шапка — не заголовок, а *штамп* (основний напис);
підписи — моноширинні, великими літерами, з розрядкою, як на кресленні;
рядки таблиці розділені пунктиром; папір кремовий; колір з'являється лише
там, де щось означає.

Назва — від штампа креслення: блок клітинок, у якому кожне значення
завжди на тому самому місці.

---

## Що переносити

Три файли й один рядок імпорту.

| Файл | Що робить |
|---|---|
| `shtamp.css` | Токени (`:root`) і примітиви `k-*`. Чистий CSS, без залежностей. |
| `tailwind.shtamp.js` | Розширення теми: радіуси, тіні, сірий ряд, «білий», шрифти. |
| Шрифти | `npm i @fontsource/manrope @fontsource/ibm-plex-mono` |

```js
// main.tsx / index.tsx
import '@fontsource/manrope/400.css';
import '@fontsource/manrope/500.css';
import '@fontsource/manrope/600.css';
import '@fontsource/manrope/700.css';
import '@fontsource/manrope/800.css';
import '@fontsource/ibm-plex-mono/400.css';
import '@fontsource/ibm-plex-mono/500.css';
import '@fontsource/ibm-plex-mono/600.css';
import './design/shtamp/shtamp.css';
```

```js
// tailwind.config.js
import shtamp from './design/shtamp/tailwind.shtamp.js';
export default { content: ['./index.html', './src/**/*.{ts,tsx}'], theme: { extend: shtamp } };
```

Шрифти беруться локально, а не з Google: у цеху інтернет буває поганий,
а вигляд має лишатись той самий.

**Важливо:** підміна `white` і `gray` у темі — це головний важіль. У коді
лишаються ті самі `bg-white`, `rounded-2xl`, `shadow-lg`; змінюється те,
що вони означають. Тому перевести чужий проєкт коштує один файл.

## Вісім правил

1. **Колір лише там, де щось означає.** Стан, попередження, гроші. Решта —
   теплий сірий. Акцент один: `--accent`.
2. **Числа моноширинні й вирівняні праворуч.** Стовпчик чисел має читатись
   як стовпчик, а не як текст.
3. **Однакова висота рядків.** Довге значення обрізається трьома крапками,
   повний текст — у підказці. Один рядок удвічі вищий — і око спотикається
   на кожному екрані.
4. **Порожнє — це риска, а не порожнеча.** `—` кольору `--line-2` по центру.
5. **Підписи моно, великими, з розрядкою.** Значення — звичайним шрифтом.
   Ця пара тримає всю систему.
6. **Рамка замість тіні.** Тінь лише під тим, що справді лежить над
   сторінкою: шторки, попапи, тости.
7. **Прямі кути.** Радіуси 5–11 px. Прилад не буває заокругленим.
8. **Поле вводу має бути видно.** Кремове поле з волосяною рамкою на
   кремовому аркуші — це не мінімалізм, а загадка. Клас `k-input`:
   біла клітинка, чітка рамка, помаранчевий фокус.

## Складові

### Штамп сторінки
Шапка — сітка клітинок: ліворуч назва й статус, праворуч значення з
моно-підписами. Дані завжди на тому самому місці.

```html
<div class="flex items-stretch border-b" style="border-color: var(--ink); border-bottom-width: 1.5px">
  <div class="flex items-center gap-3 px-3.5 py-2 flex-1 border-r" style="border-color: var(--line)">
    <span class="font-mono text-[18px] font-semibold">27/07</span>
    <span class="k-chip">Виконується</span>
    <span class="font-extrabold text-[13.5px] pl-3 border-l" style="border-color: var(--line)">ТОВ «НУМО»</span>
  </div>
  <div class="flex flex-col justify-center px-3.5 py-2 border-r" style="border-color: var(--line)">
    <span class="k-label">Позицій</span><span class="k-value">378</span>
  </div>
  <!-- …решта клітинок -->
</div>
```

### Штамп-показник
Блок у рамці `k-frame`: заголовок `k-head`, усередині клітинки з підписом,
значенням і смужкою заповнення. Смужка показує **пропорцію**, а не тільки
цифру — `131 / 378` із коротким відрізком читається миттєво.

### Таблиця
Клас `paper-table` дає все одразу: моно-шапку з жирною лінією знизу,
пунктирні рядки, обрізання, підсумковий рядок у `tfoot`.

```html
<table class="paper-table w-full border-collapse">
  <thead><tr><th>ID</th><th>Найменування</th><th>К-сть</th></tr></thead>
  <tbody>
    <tr><td class="font-mono">A21012-a1</td><td>Кришка.pdf</td><td class="text-right font-mono">200</td></tr>
  </tbody>
  <tfoot><tr><td colspan="3">Показано 9 з 378 позицій</td></tr></tfoot>
</table>
```

### Меню
Розділи — `k-label` з лінійкою до краю. Активний пункт: смужка
`border-left: 3px solid var(--accent)` і фон `--accent-soft`. Ніяких
емодзі-плиток; значки — контурні, 15 px.

### Чіпи
`k-chip` для всього, що є позначкою: операція, тип файлу, статус.
Колір задається через `background` / `color` / `border-color` з
семантичної пари (`--green` + `--green-bg` + `--green-line`).

### Мітка ШІ
`k-ai` — обведений моно-чіп `AI` синім. Ставиться біля функцій, які
читають документи самі. Такі функції збираються в окремий розділ меню
(«Читає креслення»), щоб було видно, де працює машина.

### Тост
Біле поле з тонкою рамкою; стан несе кольорова смуга зліва й значок.
Не суцільна зелена плашка: повідомлення має читатись як службова
відмітка й не сперечатись за увагу з даними.

## Чого не робити

- Градієнтів. Пробували на мітці AI — виглядало як наліпка.
- Пастельних заливок для чіпів: після п'яти штук екран стає строкатим.
  Замість заливки — обведення й кольорова крапка.
- Розділяти «хром» і «папір» різними тонами. Пробували: екран
  розпадається на програму з вікном усередині. Кремовий — на всю поверхню.
- Емодзі в інтерфейсі. У даних користувача — скільки завгодно.

## Походження

Виросло з ERP Металообробка (серпень 2026). Джерело форми — ЄСКД:
основний напис, специфікація, пунктирні розділювачі. Перевірено на
екранах із 342 і 459 позиціями — саме на таких обсягах видно, чи
тримає система ритм.
