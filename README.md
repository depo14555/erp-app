# ERP Металообробка — мобільний додаток

PWA-додаток до ERP-системи в Google Таблицях: замовлення, статуси і чат із виконавцями
зі смартфона або ноутбука.

## Що вміє

**📋 Замовлення**
- Список карток: номер, клієнт, статус (кольорова смуга), прогрес позицій, дати запуску/терміну
- Пошук за номером, клієнтом, шифром; фільтр за статусом
- Зміна статусу замовлення — пишеться прямо в шапку картки таблиці

**🗂️ Картка замовлення**
- Позиції з підгрупами за типом файлу: креслення (PDF), файли різу (DXF), 3D-моделі
- Операція, кількість, матеріал, товщина, виконавець, примітка
- Посилання на креслення і на папку замовлення в Drive
- Статус кожної позиції змінюється в один дотик

**💬 Чат**
- Треди по виконавцях із лічильником непрочитаних
- Переписка бульбашками, надсилання повідомлень
- Ті самі дані, що у вкладці 💬 Пульта керування в таблиці

**📱 PWA**
- Встановлюється як застосунок (Android/iOS/десктоп)
- Кеш даних на 5 хвилин + показ останнього стану офлайн
- Плашка «Доступна нова версія» при оновленні

## Стек

React 18 · TypeScript · Vite · Tailwind CSS · vite-plugin-pwa · lucide-react

## Підключення до таблиці

Дані беруться з Apps Script Web App таблиці-хаба (дії `erp.*`, файл `_MobileApi.js`).

1. У таблиці: Розширення → Apps Script → Налаштування проєкту → Властивості скрипта →
   переконайтесь, що є `API_AUTH_SECRET`
2. Відкрийте додаток і введіть це значення як ключ доступу (зберігається лише на пристрої)

URL веб-застосунку задається в `src/api.ts` (`WEB_APP_URL`).

## Розробка

```bash
npm install
npm run dev        # локальний запуск
npm run typecheck  # перевірка типів
npm run build      # збірка в dist/
```
